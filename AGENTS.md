# BalCheck.in — Agent Instructions

**balcheck.in** — Bank missed-call balance directory. Astro static site served by a Cloudflare Worker with static-assets binding.
Stack: Astro 7, TypeScript, Tailwind CSS 4, Cloudflare Workers

## Critical Rules
1. **Never deploy manually** — push to main triggers GitHub Actions
2. **Mobile-first** — rural users on basic smartphones
3. **Hindi language** — all content in Hindi, UI labels in English
4. **Build must pass** before any commit
5. **Data accuracy** — bank numbers must be from official sources. Include source URL in data file comments.

## Commands
```bash
npm run dev       # Dev server (localhost:4321)
npm run build     # Production build
npm run preview   # Preview with Wrangler
```

## Project Structure
```
src/
  pages/
    index.astro              # Main page (directory + search + category tabs)
    how-it-works.astro       # How-to guide page with HowTo + FAQPage schema
    bank/[slug].astro        # 79 bank detail PSEO pages (BankOrCreditUnion + FAQPage + HowTo + BreadcrumbList schema)
    banks/[category].astro    # 7 category listing pages (CollectionPage + ItemList schema)
  layouts/Layout.astro       # HTML layout, meta tags, GA4
  components/SchemaOrg.astro # JSON-LD structured data (homepage)
  data/banks.ts              # Bank missed-call number database (79 banks, 7 categories)
public/
  favicon.svg
  og-image.svg              # Social share image (Layout.astro og:image/twitter:image)
  robots.txt                 # Sitemap: https://balcheck.in/sitemap-index.xml
```

## Brand / Design System
- Brand tokens + component rules: `docs/brand-tokens.md` (implemented in `src/styles/global.css` @theme).
- Global utilities `scrollbar-hide` and `scroll-fade` live in `global.css` — use them for ALL horizontal scroll rails; do not redefine them in page <style> blocks.
- Sitewide footer links live only in `SiteFooter.astro`; never add inline page footers.

## PSEO Pages
- **79 bank pages** at `/bank/[slug]` — each with BankOrCreditUnion, FAQPage, HowTo, BreadcrumbList schema
- **7 category pages** at `/banks/[category]` — CollectionPage + ItemList schema
- **9 vertical routes** — `/customer-care/[slug]`, `/net-banking/[slug]`, `/sms-banking/[slug]`, `/mini-statement/[slug]`, `/mobile-number-registration/[slug]`, `/aadhaar-link/[slug]`, `/atm-pin/[slug]`, `/balance-enquiry/[slug]`, `/toll-free-number/[slug]` — each with 79+ pages + hub
- **Merged-banks vertical** — `/merged-banks/[oldSlug]` (11 legacy RRB merger pages) + `/merged-banks/` hub — data in `src/data/mergers.ts`, successor numbers rendered from `banks.ts` only
- **How-to page** at `/how-it-works` — HowTo + FAQPage schema
- Sitemap auto-generated by @astrojs/sitemap at `/sitemap-index.xml`
- Fresh-build baseline: 823 generated pages. Recompute from `dist/` and the sitemap instead of assuming this count is permanent.

Push to `main` → GitHub Actions → Cloudflare Worker. Never use `wrangler deploy` directly.
